# 写作总纲：《外太空经济》扩写（多哈演讲底稿）

## 背景
- 作者（北京，2026年10月）将于2026年10月底在卡塔尔多哈做主题演讲，本稿是演讲的完整底稿/讲义。
- 原始提纲见 `source/outline.md`（作者自己的笔记，含若干数据口径不一致或需核实之处）。
- 全稿共五部分，每部分约 **2万字**（用 `python3 common/wordcount.py partN/*.md` 计数，目标 20,000–22,000，正文不含图片行）。合计约10万字。
- 今天是 2026-10-08。写"截至目前"时以2026年10月为时点。

## 全书结构与章节编号（统一，不得改动章号）
- 第一部分　进入太空：卫星、火箭与载人航天 —— 第1章 卫星发射数量；第2章 火箭技术；第3章 载人飞行器；第4章 空间站；第5章 航天飞机；第6章 太空望远镜
- 第二部分　太空的"土地"与"矿藏"：轨道、资源与国家战略 —— 第7章 太空轨道；第8章 太空资源；第9章 各国太空战略
- 第三部分　重返月球，奔向火星 —— 第10章 月球开发；第11章 火星开发
- 第四部分　太空的规则：法律、治理与秩序 —— 第12章 国际空间法体系；第13章 频轨资源、太空交通与碎片治理
- 第五部分　太空经济与人类文明 —— 第14章 太空产业规模和结构；第15章 太空技术、经济与战争；第16章 太空文化、文明和太空移民

## 文风
- 简体中文，面向政商学界的高端听众：有观点、有逻辑、有数据，深入浅出，可直接用于演讲。避免空话、口号、堆砌形容词。
- 每章结构建议：开篇一个抓人的事实或问题 → 分节展开（二级/三级标题）→ 数据与案例 → 趋势判断 → "本章要点"（3–5条，适合直接做演讲PPT要点）。
- 每部分开头写一段约500–800字的"导语"，说明本部分要回答什么问题、与全书主线（太空正从"国家工程"变成"经济体系"）的关系。
- 逻辑主线：成本下降（发射成本、卫星制造成本）→ 规模爆发（星座、发射次数）→ 资源稀缺（轨道、频谱）→ 规则竞争 → 产业与文明格局重塑。各部分尽量呼应这条主线。
- 演讲在多哈：适当加入海湾/中东视角（如阿联酋"希望号"火星探测器与宇航员计划、沙特航天局与宇航员、卡塔尔Es'hailSat卫星公司、海湾国家主权基金对航天的投资、中阿航天合作等），但不要喧宾夺主，每部分有1–3处自然结合即可。
- 作者在北京：中国视角要充分（中国航天数据、商业航天、星网/千帆等），同时保持客观，对中美欧俄等各方实事求是。

## 数据要求（最重要）
- 必须用 WebSearch/WebFetch 核实关键数字，优先权威来源：Jonathan McDowell 的 planet4589 统计、UCS卫星数据库、ESA年度空间环境报告、NASA/ESA/CNSA/CMSA官网、SpaceX官方、Space Foundation《The Space Report》、Euroconsult、Novaspace、BryceTech、麦肯锡/世界经济论坛《Space: The $1.8 Trillion Opportunity》、OECD《The Space Economy in Figures》、ITU、UNOOSA、中国国家航天局、新华社等。
- 原始提纲中的数字如有口径矛盾或错误（例如"2023年约2900颗，增长到2024年约2800颗"这种自相矛盾的表述），要纠正，并在本部分末尾的"数据核查说明"中逐条写明：原文说法 → 核实结果 → 来源。
- 提纲中有一些2026年下半年的事件（如星舰第13/14次飞行、罗曼望远镜发射、神舟二十三号等）。能检索到就按检索结果写；**检索不到可靠来源的，不要编造细节**——可保留作者原述并标注"据作者提供资料"，同时列入"数据核查说明"提请作者确认。
- 不能编造数据、引语或来源。估算或预测必须注明是谁的预测。
- 数字写法：用阿拉伯数字，注明年份与口径（如"2025年全球入轨航天器约4500个（McDowell口径）"）。

## 图表要求
- 每部分 **6–10张图**（matplotlib）+ 若干Markdown表格。图要服务论点：趋势用折线/柱状，结构用堆叠柱或横向条形，对比用分组柱，时间线用横向时间轴图。不做3D、不做饼图过多（饼图最多1张）。
- 图表脚本放在 `partN/charts/figN-M_简短英文名.py`，用共享样式：
  ```python
  import sys, pathlib
  sys.path.insert(0, str(pathlib.Path(__file__).resolve().parents[2] / "common"))
  from chartstyle import plt, PALETTE, ACCENT, GREY, save, source_note
  fig, ax = plt.subplots(figsize=(8, 4.5))
  ...
  ax.set_title("图标题（单位）")
  source_note(fig, "数据来源：……")
  save(fig, __file__)   # 输出同名 .png
  ```
  运行：`python3 -I partN/charts/xxx.py`。每张图必须运行成功并用 Read 工具查看一次PNG，确认中文正常、无重叠、可读。
- 图编号按章：图1-1、图1-2……图7-1……；表编号同理：表1-1……
- 正文引用图片的写法（单独一行，前后空行）：
  `![图1-1　2015—2025年全球年度入轨航天器数量](charts/fig1-1_launch_trend.png)`
  并在正文中用"如图1-1所示"之类的话引用它。
- 表格用Markdown管道表格（pipe table），表题写在表格上方单独一行：`**表1-1　主要运载火箭参数对比**`。
- 可引用作者原有的两张图：`../source/image1.jpeg`（北斗三类轨道示意）与 `../source/image2.jpeg`（大气分层高度），仅第二部分第7章使用。

## 文件与格式
- 每部分写在 `partN/` 下，按章拆文件，便于分批写作：`partN/00_intro.md`（部分标题+导语）、`partN/ch01.md`……、`partN/zz_notes.md`（本部分"数据来源"与"数据核查说明"）。文件名排序即正文顺序。
- 标题层级：部分标题用 `# 第一部分　……`（只在00_intro.md里出现一次）；章用 `## 第1章　……`；节用 `### 1.1　……`；小节用 `#### ……`。
- 不使用HTML，不使用脚注语法；来源可在段末用括号简注，如（来源：ESA《2025空间环境报告》），完整来源清单放 zz_notes.md。
- 不要修改 `common/` 和其他部分的目录。
