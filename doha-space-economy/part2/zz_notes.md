### 数据核查说明（原文说法 → 核实结果 → 来源）

1. "SpaceX拿到监管许可的星座总上限为42000颗" → 不准确。42000颗是约1.2万颗已获批加2019年向ITU申报的3万颗之和，为规划上限；截至2026年10月FCC实际批准约1.9万颗（Gen1 4408颗加Gen2 15000颗）→ FCC文件、Spaceflight Now（2019）、Via Satellite（2026）。
2. "一期550公里4408颗、二期340公里7518颗、三期3万颗" → 部分准确。4408颗分布在540—570公里五个壳层，并非全在550公里；7518颗为2018年批准的约340公里V频段系统；"三期3万颗"为ITU申报，Gen2实获批15000颗 → 同上。
3. "275公里：V3卫星运行在这一超低轨道" → 修正为"星舰第14次飞行在约275公里释放V3卫星，卫星随后自行升轨" → 飞行前计划及发射后报道（2026年9月）。
4. "倾角覆盖43°至97°" → 修正为33°至约97.6°（Gen2首批含33°壳层）→ FCC 2022年12月授权。
5. "2026年1月启动重组，约4400颗由550公里降至480公里" → 属实，公告日期为2026年1月1日 → SpaceX尼科尔斯公告。
6. "GEO约1800个轨位" → 1800为按0.2°间隔的理论数；按2°间隔单一频段约180个 → 行业资料、McDowell（2026年2月）。
7. "高地球轨道（GEO）：高度35786公里以上" → 修正：GEO为35786公里的特定圆轨道；HEO通常指大椭圆轨道。
8. 大气分层数字（提纲与作者原图不一致）→ 各层边界随纬度和太阳活动变化，正文采用区间表述；原图标注见第19条。
9. 北斗三号"24 MEO+3 IGSO+3 GEO" → 属实；30颗于2020年6月23日发射完毕，7月31日正式开通 → 中国卫星导航系统管理办公室、UNOOSA。
10. "2万个直径超10厘米的太空碎片" → 已过时。ESA 2025年报告：>10厘米约5.4万个（模型）；2026年7月被跟踪约47070个 → ESA。
11. 范艾伦辐射带条目未写完 → 已补全（内外带高度、粒子、危害、南大西洋异常）→ NICT等。
12. "天工开物：2030年前形成深空勘探能力，2040年前小规模开发" → 未找到出处。公开信息为：2026年1月由中国航天科技集团提出开展专项"论证"；长期设想节点为2035、2050、2075、2100年 → 新华社、SpaceNews。
13. 行动计划"2025年11月发布" → 属实，国家航天局印发，五方面22项举措 → 中国新闻网、新华网。
14. 各国政府航天预算（第二轮已核实）→ 2024年：美国797亿、中国约199亿（外部估算）、日本68亿、欧盟机构67亿、俄罗斯40亿、法国37亿、德国28亿、意大利26亿美元，新增图9-3；占GDP比重为作者按IMF数据计算 → Novaspace第24版（Statista转引）、IMF。阿联酋、沙特仅见二手资料。
15. 星链避碰机动（第二轮已核实）→ 2023年6—11月24410次；2024年12月—2025年5月144404次；"约5万"一期报道为"近5万次"，图7-5已补齐 → Space.com、Space Intel Report。
16. 7518颗V频段授权（第二轮已核实）→ 2018年单独批准，后以第二代卫星搭载V频段载荷实施，2024年11月获准在340—360公里使用V频段，故不另计 → Communications Daily、Satnews。
17. 空间太阳能（第二轮）→ OHISAMA计划由Kairos火箭发射，Kairos 2026年3月第三次失败，未见发射报道；"逐日工程"2026年5月地面验证百米级约1.2千瓦、效率20.8% → 新华社。
18. 第二轮已核实：沙克提约400块（NASA估计，编目约100块）；LCROSS含水5.6%±2.9% → Colaprete等（2010）；中阿北斗/GNSS中心2018年4月在突尼斯揭牌 → GPS World；韩国2032年登月属实，2026年7月新增2030年民营小型着陆器计划 → 韩国媒体。
19. 原图"伽马射线100千米"→ 判断应为"卡门线100千米"：100公里正是卡门线的通用高度，伽马射线并无对应100公里的分界，且原图其余标注均为分层边界。建议改图。
